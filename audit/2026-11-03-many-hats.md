# Many hats review, 2026-11-03

Scott asked (2026-11-03): look at the app as a designer, coder, systems admin, supervisor and associate. What could be better, how would an associate take the feedback, and does the wording make sense?

**How it was checked:** the live backup (`state/latest.json`, pulled 2026-11-03 21:10Z, 73 weeks, 7 YTD files) was loaded into a sealed local copy of v2026.10.27.2 in headless Chrome. Every cloud call was blocked. Every page was opened, and the real Tuesday messages for this week were generated and read. The same copy was then run with the clock set to January 5, 2027. A separate read-only pass covered sync, storage, security and the year turnover. Nothing in the app was changed.

This file is in a public repo, so associates are not named here.

## What is working
- The Calls page is the best part of the app. Paste, scorecard, quotes with times, and "4 of the 7 that applied" all line up, and the read is right on the test call.
- The high fives are short, warm and specific. An associate would be glad to get one.
- Quarterly review prep: each quarter is built from its own uploads, and the check-in document is clear.
- The Copilot prompt on the Coach page is well built: wins first, at most two focus areas, one tip each, no hours.
- A failed cloud save shows a warning toast ("saved on this computer but did not reach the cloud").

## 6. Systems admin hat
Read only, against the code. The top items were re-checked by hand: X1 cause, X2, X4, X8.

| # | Finding | Where | Fix |
|---|---|---|---|
| X1 | **The cloud copy can be overwritten from a second tab, or from a browser that has not pulled yet.** A store's push only checks that the cloud copy as a whole has not moved since this machine last read it, not what the local store was built from. Two tabs share one sync record, and a pull in one tab never tells the other. The worker accepts an empty or shrunken store. Example: the home PC uploads overnight, tab B still holds yesterday, Scott pastes a daily in tab B, and the home upload is gone from the cloud. | `manifest-sync.module.js` 23, 51-67, 336-370, 484, 526; `storage.module.js` 187-207; worker `index.js` 213-232 | Send the version each store was based on.
